# 杰德生产管理系统

## 产品资料与价格

每个产品仍对应一条产品记录。产品详情和编辑页面分为“基本信息”和“技术资料”两个页签：基本信息维护图号、名称、客户、包装、组装图号及每套用量；技术资料维护图纸、作业指导书、材料和检验要求。

产品只保存一个当前单价和币种。管理员、财务人员或具有“查看产品及发货价格”权限的人员可以查看价格；修改价格还需要产品编辑权限。没有价格的产品仍可下单和发货。

## 发货价格快照

普通发货和组装发货的每条配件明细都会保存发货当时的单价和币种。以后修改产品当前价格，不会改变历史发货金额。升级前的历史发货不会自动套用当前产品价格，可由同时具有发货管理和价格查看权限的人员手工补录。

发货明细加入有效开票单后，发货日期、数量、产品和价格会锁定；不影响金额的物流备注仍可维护。需要纠错时，先从待开票单移除该明细，或作废已开票记录。

## 客户开票资料与财务流程

在客户列表进入“开票信息”，维护开票抬头、税号、注册地址、注册电话、开户银行、银行账号和收票邮箱。创建开票单时会保存一份客户资料快照，客户以后修改资料不会改写历史开票单。

财务模块按客户和币种选择尚未占用且已有价格的普通发货或组装配件明细。开票单流程为“待开票 → 已开票 → 已收款”；已收款可先撤销收款，已开票记录可作废，作废后关联发货明细会重新释放。系统不支持部分收款。

财务详情页可单独导出 Excel 和 PDF，内容包括客户开票资料、发票信息、发货来源、数量、单价和总金额。普通送货单及其邮件附件始终不包含价格、税号或银行账号。
