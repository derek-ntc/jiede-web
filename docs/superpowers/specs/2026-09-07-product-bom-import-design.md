# 产品组装清单批量导入设计

## 背景与目标

客户现有 Excel 在同一个工作表中按“组装件DZ-30”“组装件DZ-31”等标题连续排列多个物料清单区块。每个区块都有物料编码、物料名称、规格型号、单位、每套数量五列。不同组装件会重复列出共用零件，也会分别列出各自专用零件。

本功能的目标是直接导入这种多区块 Excel，不要求用户先整理成新的平铺模板：

- 批量创建或更新产品基本信息，图纸、作业指导书和其他技术资料仍可日后逐个上传。
- 同一零件在多个区块出现时只保留一条产品记录，并为它建立多个组装件关联。
- 专用零件只关联它所在的组装件。
- 导入前展示可核对的预览，用户确认后才写入数据库。
- 已有产品的图纸、价格、技术资料和未出现在本次文件中的组装关系均不被删除或覆盖。

## 输入格式与字段映射

系统读取工作簿的活动工作表。组装区块由标题行开始，标题首个非空单元格须以“组装件”开头，例如“组装件DZ-30”。标题中的“组装件”前缀和首尾空格会被移除，保存的组装图号为 `DZ-30`。

标题后的表头支持以下五列，列顺序可以变化，但列名必须可识别：

| Excel 列 | 产品字段 | 规则 |
| --- | --- | --- |
| 物料编码 | `manuals.sku` | 去除首尾空格；数值编码保留可见文本 |
| 物料名称 | `manuals.product_name` | 必填 |
| 规格型号 | `manuals.drawing_no` | 必填，作为产品匹配主键 |
| 单位 | `manuals.unit` | 保存例如 `PCS`；新字段，旧产品默认为空 |
| 每套数量 | `product_assembly_components.quantity_per_set` | 必须为正整数 |

标题区块之外、空白行、重复表头及第五列以后的辅助列均忽略。单元格颜色不参与任何业务判断；黄色、绿色只作为原表中的人工视觉标记。

## 客户与产品匹配

导入页面必须选择客户。本次业务使用“宁波知了智能科技有限公司”，但页面保留客户选择，以便后续导入其他客户的组装清单。

产品以“客户 + 产品图号（规格型号）”进行不区分大小写的匹配：

- 未找到匹配产品：创建一条不含附件的新产品。
- 找到唯一产品：复用该产品，并用 Excel 中的物料名称、物料编码和单位更新基本字段。
- 同一客户下找到多个相同产品图号：整批拒绝，提示先处理产品重复记录。
- 相同产品图号属于其他客户：不复用，按当前所选客户创建新产品。

同一份 Excel 内，重复出现的产品图号必须具有一致的物料编码、物料名称和单位；任一字段冲突时整批拒绝并指出行号。

## 组装关系规则

每个有效 Excel 行形成一个“产品—组装图号—每套数量”关系。同一产品在 DZ-30 和 DZ-31 区块出现时只创建或匹配一次产品，并分别保存两条关系。

确认导入时：

- 已有相同组装图号关系更新每套数量。
- 不存在的组装关系追加创建。
- 产品已有但本次 Excel 未包含的其他组装关系保留。
- 同一产品和同一组装图号在文件中重复且数量相同，合并为一条；数量不同则拒绝整批导入。

## 预览与写入

导入分为两个步骤：

1. 上传 Excel 并选择客户。服务器解析、校验并显示预览，包括组装件数量、新增产品数、匹配产品数、将新增或更新的组装关系数，以及逐行明细。
2. 用户点击确认导入。服务器验证签名预览令牌、重新检查当前数据库匹配状态，并在单个数据库事务中完成所有创建和更新。

预览内容通过应用密钥签名，浏览器不能篡改客户、产品或数量。确认令牌无效时不写入任何数据，并要求重新上传预览。解析错误、字段冲突、重复产品或非法数量同样不产生部分写入。

## 页面与权限

产品列表标题区增加“Excel导入组装清单”按钮，仅拥有 `product_create` 权限的账号可见和访问。导入页沿用现有后台表单、按钮、深色文字和边框风格。

产品基本信息页增加“单位”字段。产品列表增加紧凑的“单位”列，并继续显示“所属组装件”中的多个组装图号及每套数量。

## 不包含

- 不从 PNG/JPG 图片执行 OCR 导入。
- 不依赖单元格底色判断共享或专用零件。
- 不在导入时上传图纸或技术附件。
- 不导入或覆盖价格、材料、包装、库存、供应商及技术参数。
- 不删除任何既有产品、附件或组装关系。
