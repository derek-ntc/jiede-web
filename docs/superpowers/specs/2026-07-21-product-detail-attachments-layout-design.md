# 产品详情页附件布局调整设计

## 目标

取消产品详情页中的“库存二维码”卡片，并让现有“附件”卡片占用原二维码卡片所在的右侧位置。顶部“打印标签”按钮继续保留。

## 页面布局

- 桌面端继续使用现有两列详情布局：左侧为“产品信息”，右侧为“附件”。
- 删除“库存二维码”标题、二维码图形、库存编码提示及该卡片内的库位库存列表。
- 附件卡片保留现有图片展示、PDF 悬浮预览、非 PDF 文件打开和“暂无附件”状态。
- 手机端沿用现有单列响应式布局，产品信息在前，附件在后。

## 保留范围

- 产品信息中的库存编码、当前库存、默认库位和最低库存字段不变。
- 页面顶部“打印标签”按钮及其权限控制不变。
- 不修改库存接口、库存数据库、二维码标签打印页或其他页面。

## 验收条件

- 有库存管理权限的用户打开产品详情页时，不再看到“库存二维码”和 `data-qr-code` 元素。
- 产品详情页仍显示“附件”卡片，且附件位于详情网格第二项。
- “打印标签”按钮仍然存在。
- PDF 预览和非 PDF 文件打开行为保持不变。
- 全量自动化测试通过，并在 VPS 部署后确认服务正常。
