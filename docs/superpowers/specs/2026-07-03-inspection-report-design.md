# 成品检验报告设计

## 目标

在产品资料中维护结构化检验要求。计划发货清单生成后，可以直接调用清单内各产品的检验要求，生成一张可打印填写的成品检验报告。发货后，可以把填写完成的报告文件上传到对应计划发货清单归档。

## 范围

- 每个产品维护多行检验要求。
- 每行检验要求包含：检验项目、标准要求、检验方法/工具、备注、排序。
- 产品详情页显示检验要求。
- 产品编辑页可以新增、修改、删除、排序检验要求。
- 计划发货清单卡片增加检验报告入口。
- 检验报告预览页按计划单产品明细自动带出产品检验要求，并提供打印。
- 计划发货清单支持上传完成后的检验报告文件，并在计划单卡片中显示已上传报告。

## 数据设计

- 新增 `manual_inspection_requirements` 表，按产品保存结构化检验要求。
- 新增 `shipment_plan_inspection_reports` 表，按计划发货清单保存上传后的报告文件。
- 上传文件存放在 `uploads/inspection-reports`。
- 报告预览不复制产品检验要求；每次打开时读取产品当前检验要求。

## 页面设计

- 产品详情页：在“作业指导书”附近新增“检验要求”板块，以表格显示。
- 产品编辑页：新增“检验要求编辑”表格，每行可填写项目、标准、方法/工具、备注，支持增删行。
- 发货页计划发货清单：增加“检验报告”按钮、“上传完成报告”文件输入和已上传文件列表。
- 检验报告预览页：沿用计划发货清单预览的打印风格，报告头显示报告编号、计划单号、客户、计划发货日期、生成日期；明细按产品分组显示检验项目。

## 行为规则

- 产品没有维护检验要求时，报告里显示一行空白提示，方便现场手写。
- 上传报告文件必须属于已有计划发货清单。
- 删除计划发货清单时，级联删除报告记录；文件清理可在实现中同步处理。
- 只允许已有上传白名单内的常见文件类型，和产品附件保持一致。

## 验证

- 自动测试覆盖检验要求保存、读取和计划报告数据组装。
- 手动验证产品编辑页、产品详情页、计划发货清单、检验报告预览和上传归档流程。
