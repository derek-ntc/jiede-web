# PDF 悬浮预览设计

## 背景与目标

生产跟进和产品资料中的 PDF 链接目前直接指向原始 PDF 文件。服务器已经返回 `Content-Type: application/pdf` 和 `Content-Disposition: inline`，但部分浏览器仍会把直接打开 PDF 处理为下载，且不同浏览器的原生 PDF 工具栏行为不一致。

本次改动的目标是：

- 点击生产跟进或产品资料中的 PDF 时，不跳转、不自动下载。
- 在当前页面上方弹出大尺寸悬浮预览层。
- 提供缩小、放大、当前缩放比例、打印 PDF 和关闭功能。
- 不提供下载按钮。
- 非 PDF 文件保持现有打开方式。
- PDF 阅读器所需资源随项目部署，不依赖外部 CDN。

## 方案选择

采用项目内置 PDF.js 的自定义悬浮阅读器。未采用浏览器原生 PDF 工具栏，因为原生工具栏通常包含无法稳定隐藏的下载按钮，且各浏览器行为不一致。未采用服务端转图片，因为它会降低打印质量并增加服务器计算和存储开销。

## 架构

### PDF 数据接口

沿用现有受控文件接口：

- 产品资料 PDF：`/manuals/<filename>`
- 生产跟进 PDF：`/admin/production-followups/files/<file_id>`

接口继续返回原始 PDF 字节。生产跟进接口保持登录校验，产品资料接口保持当前权限行为。响应明确使用 `application/pdf` 和内联展示，不增加新的任意 URL 代理接口，避免服务器被用于读取外部地址。

### 通用预览组件

在公共页面布局中加入一个默认隐藏的 PDF 预览对话框。组件包含：

- 文件名标题。
- “缩小”按钮。
- 当前缩放比例。
- “放大”按钮。
- “打印PDF”按钮。
- “关闭”按钮。
- 可滚动的多页 PDF 渲染区域。
- 加载中、加载失败和空文件提示。

组件只创建一次，由生产跟进和产品资料页面共用。页面中的 PDF 链接改为带 `data-pdf-preview-url` 和 `data-pdf-preview-name` 的预览触发器；非 PDF 链接不增加该属性。

### PDF.js 资源

将固定版本的 PDF.js 浏览器构建文件和 worker 文件放入 `static/vendor/pdfjs/`。版本在项目内固定并随代码同步到 VPS，不使用运行时 CDN。

## 交互流程

1. 用户点击 PDF 文件名或“预览”按钮。
2. JavaScript 阻止默认跳转并打开悬浮预览层。
3. 预览组件通过现有文件 URL 加载 PDF。
4. PDF.js 按页渲染到 canvas，初始缩放以适合预览区宽度为准。
5. 用户可按固定步长缩小或放大，比例限制在合理范围内。
6. 点击“打印PDF”时，使用原始 PDF 地址在隐藏打印框架中调用浏览器打印；打印成功与否不改变当前预览状态。
7. 点击关闭按钮、遮罩空白区域或按 Escape 关闭预览并释放当前 PDF 渲染资源。

## 缩放与布局

- 初始比例按可用宽度自动计算，上限为 100%。
- 每次缩放调整 25%。
- 最小比例 50%，最大比例 300%。
- 多页 PDF 垂直排列，页面之间保留小间距。
- 桌面端预览层占视口约 92% 宽、92% 高。
- 手机端工具栏允许换行，预览层接近全屏。
- 放大后使用预览区域自身的横向和纵向滚动，不影响后台页面滚动位置。

## 打印行为

- 界面只提供“打印PDF”，不提供下载按钮。
- 打印使用原始 PDF 内容，不打印后台导航、预览工具栏或遮罩。
- 打印调用失败时显示明确提示，不自动转为下载。

## 错误处理

- URL 返回 404 或无权限：预览层显示“PDF 文件不存在或无权访问”。
- 返回内容不是有效 PDF：显示“PDF 文件无法解析”。
- worker 加载失败：显示“PDF 预览组件加载失败，请刷新后重试”。
- 快速切换文件或关闭窗口：取消或忽略上一次未完成的渲染，避免旧文件覆盖新预览。
- 打印窗口被浏览器拦截：显示“浏览器阻止了打印窗口，请允许弹窗后重试”。

## 页面改动范围

- `templates/base.html`：挂载通用 PDF 悬浮预览组件和脚本入口。
- `templates/production_followups.html`：PDF 文件链接改为预览触发器。
- `templates/detail.html`、`templates/preview.html`：产品 PDF 的打开入口改为预览触发器。
- 产品列表通过“图纸预览”进入的页面复用同一组件。
- `static/style.css`：新增桌面端和移动端预览样式。
- `static/pdf-preview.js`：管理加载、渲染、缩放、打印、关闭和错误状态。
- `static/vendor/pdfjs/`：固定版本 PDF.js 和 worker 资源。

## 测试策略

### 自动化测试

- 产品资料 PDF 响应为 `application/pdf` 且内联展示。
- 生产跟进 PDF 响应为 `application/pdf` 且内联展示，并保持登录限制。
- PDF 链接带有预览触发属性，非 PDF 链接不带该属性。
- 公共布局包含唯一的预览对话框、缩放按钮、打印按钮和关闭按钮。
- 页面中不存在新增的 PDF 下载按钮。

### 浏览器验证

- 点击产品资料 PDF 后在当前页面悬浮预览。
- 点击生产跟进 PDF 后在当前页面悬浮预览。
- 多页渲染、50% 到 300% 缩放、关闭和 Escape 正常。
- 打印预览内容是 PDF 本身，不包含后台页面。
- 桌面和手机宽度下工具栏及页面滚动正常。

## 非目标

- 不修改 PDF 文件内容。
- 不增加 PDF 编辑、批注、签名或旋转功能。
- 不改变图片、DWG、Excel、Word 等非 PDF 文件的打开方式。
- 不追踪或记录用户预览、缩放和打印行为。
