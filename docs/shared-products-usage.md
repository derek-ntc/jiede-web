# 共用产品、供应商银行信息与送货单样式

## 共用产品

- Excel 导入时，产品图号、产品名称、规格型号三项相同的产品可复用现有产品，新增适用客户，不再按客户重复建立产品。
- 仍只有一个客户的旧产品可通过重新导入修正基本资料；若全库已经有完全相同的产品，优先复用准确匹配的产品。
- 产品列表、详情和库存显示适用客户。选择任意适用客户都能找到同一产品及其共用库存。
- 产品编辑页可增加适用客户；组装件行带有客户字段，同一个组装件图号可在不同客户下设置不同的每套数量。
- 订单、组装发货和生产跟进仍按客户区分，发货从产品共用库存扣减。Excel 导入订单遇到多客户共用产品时须选择客户，防止误归类。
- 第二个客户导入不会覆盖产品原有 SKU 或单位；不同的导入 SKU 作为查询别名保留。两个非空单位冲突时拒绝导入，要求先核对。

## 历史数据迁移与发布注意

新版首次初始化时，在单一事务内执行一次历史合并，保留最早产品 ID，汇总同库位数量，迁移产品引用，并保存原产品及关联记录的 JSON 归档。旧产品编码保留为库存查询别名。失败则整笔事务回滚。

不同单位、不同非空价格、不同包装信息、不同显式工艺顺序，或相同客户同一组装件数量冲突的产品不会强制合并。产品列表会提示未合并的记录数和原因。此类产品需要先由业务人员核对，再安排有备份的专项处理；重启应用不会重复执行全库合并。

发布前应备份目标环境数据库及资料文件，在目标数据库副本上演练，再停写执行部署。不要用本地数据库覆盖 VPS/NAS 数据。本次本地验证没有修改线上或本地原始业务数据库。

归档表用于审计和恢复参考，并非一键撤销；合并后产生新业务时不可直接拆回。完整发布前备份仍须保留。

## 供应商

供应商新增和编辑支持付款银行、付款银行行号、付款帐号。三个字段均可留空，按文本保存，保留帐号前导零，每项最长 200 字符；支持搜索。历史采购单快照不变。

## 送货单

Excel 与 PDF 采用相同字段顺序和列宽比例，保持纵向 A4。左侧标签列加宽，元数据、公司名称及签名栏改为白底，数量列表头改为白底黑字，其余深蓝灰表头保留。长文字换行，不扩展打印宽度；零数量仍显示为 0。

验证包含 17 行样例的 Excel 打印预览与 PDF，均为一页纵向 A4。更长的清单允许纵向分页，保持单页宽度。
