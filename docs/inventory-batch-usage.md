# 批量成品入库与库存调整

## 使用入口

- 库存总览中的“批量入库”“批量调整”保留当前客户筛选。
- 生产订单中的“整单入库”带入该行的客户和订单号；原有单件“成品入库”保留。
- 入库和单件库存调整页面的“新增库位”可当场维护库位，无需离开表单。

## 入库规则

1. 选择客户，可按组装图号、完整订单号、产品名称或图号进一步筛选。
2. 勾选本次操作的明细；按组装套数计算时，套数乘每套用量，计算结果仍可手工修改。
3. 可逐行选择库位，或用统一库位应用到勾选行。新增库位后，批量页面先选中统一库位，不覆盖已填写行；点击应用按钮后生效。
4. 按订单号查询才关联订单并更新已入库数量。不选择订单号时按产品直接入库，不猜测或分摊到其他订单。
5. 超出订单剩余未入库量需要再次确认；重复发送同一批次不会重复增加库存。

## 盘点调整规则

- 填写所选产品、库位的“盘点后实际数量”，不是增加或减少的数量；允许零，不允许负数或小数。
- 更换库位不是移库，不自动减少原库位数量。
- 调整原因必填。调整按差额生成流水，不修改生产订单数量或累计入库进度。
- 页面打开后库存或关联订单进度变化时，系统拒绝过期提交，需重新查询核对。
- 同一产品和库位不能在一批中重复调整。任一行无效则整批不写入。

## 范围和维护

- 使用现有仓库库存权限。新提交和快捷库位接口校验 CSRF；查询凭证限当前账号和操作类型，有效期两小时。
- 每批最多 500 行，超过时保留查询表单并提示缩小范围。按批次查看流水可显示完整 500 行。
- 新增 `inventory_batch_receipts` 数据表用于幂等提交记录；不删除或迁移原有业务记录。
- 发布时除了 `app.py`、模板和静态文件，必须包含根目录的新模块 `inventory_batch.py`。
- 已修复全部库位停用且默认编码已占用时入库页报错的问题，以及当天流水编号超过 999 时重复的问题。
