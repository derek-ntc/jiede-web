# 发货资料、生产订单与采购页面使用说明

本轮修改先在本地实施与验证，未同步到 NAS 或 VPS，未改写实际业务数据。

## 1. 发货时自动带入收货资料

选择客户后，优先使用客户档案的收货人、收货电话和地址。收货人和收货电话都未填写时，改用客户联系人及联系电话，并提示核对；只缺其中一项时，不会混入另一位联系人的资料。

本次发货可以手动修改或留空。调整套数、重新预览配件，不会覆盖已修改的收货资料。保存的是本次送货单资料，不回写客户档案，也不改变以前的送货单。

## 2. 生产订单先看汇总，再看明细

进入“生产订单”先看到订单汇总。组装订单显示组装图号、套数和产品项数；普通订单显示产品概况。点击“查看明细”，查看产品数量、规格型号、交货期及原有操作。

支持按客户、订单号、组装图号、产品图号或名称查找。即使只搜到一个配件，进入明细仍显示其所属订单组的全部配件。不同客户的同号订单不会混在一起。

编辑后保存或取消，会返回明细并保留原有查询条件。此调整只改变展示方式，不合并原有订单记录。

## 3. 按订单明细填写生产进度

进入“生产跟进”，选择订单、查看明细，再点击产品的“开始跟进”。只有这一步才创建该订单明细的工艺卡；单纯打开页面不创建记录。

每道工艺填写“当前累计完成数量”，不是本次新增数量。例如需求 200 件、已完成 80 件，填写 80，显示 40%；再次保存 80 不会变成 160。工艺可分别填写数量和备注，也可添加、删除或调整顺序。

多人同时修改时，过期页面会提示刷新。订单需求不能改小到已完成数量以下。有数量变更历史的工艺卡，不能通过先归零再删除来清除历史。工艺进度不会自动增加库存或生成发货。

以前的工艺卡在“历史／独立工艺卡”中继续使用，不自动绑定到新订单。

## 4. 原材料采购及 Excel

采购页面按“供应商及单号 → 物品明细 → 公司收货资料 → 要求与日期”排列。选择供应商后，自动显示名称、代码、联系人、电话、邮箱和地址。

供应商资料在供应商管理中维护。已保存的采购订单保留下单时的资料；未更换供应商时，不会自动刷新历史资料。供应商地址和公司收货地址分开，不相互覆盖。

原材料明细包括：物品名称、材质、长、宽、厚度、表面、数量、单位、预计到货日期和备注。

保存后进入单据详情，点击“导出 Excel”。Excel 按横向 A4、一页宽打印，长订单可纵向分页并重复表头，包含公司标题、全部明细、收货资料和签字区域。原有采购 PDF 入口保留。

原材料 Excel 中长、宽、厚度和数量是可直接计算的数值，采用“常规”格式。原材料 Excel 与 PDF 底部固定显示交付标识、合格证及检测报告要求，以及供应商考核要求；订单自行填写的备注单独保留。纸箱、外协及其他采购不增加这两条原材料说明。

## 5. 纸箱及外协采购

采用相同订单式布局。纸箱保留长、宽、高和尺寸说明；外协保留物品／图号、尺寸、厚度、表面等字段。

有价格权限时显示单价及金额，按人民币计算；空价格表示“未录价”，不自动当作零。无价格权限的账号不能从页面数据或导出文件中查看价格。

用户提供的采购模板仅用于参考版式，没有导入模板里的示例订单或联系人。

## 6. 采购到货与库存清单导出

到货单详情提供“导出 Excel”和“预览 / 打印 PDF”。单据保留订购资料与实际到货资料对照、订购数量、实际到货数量、合格入库数量、入库库位、开票状态、库存批次及过账账号。零合格数量的到货行也保留，显示“未建库存”。已作废的到货单仍可导出，清楚标记作废状态及操作人。

采购库存页先选类别及查询条件，再点击“导出当前筛选 Excel”。导出包含入库数量、当前可用数量、供应商、订单、到货单、库位及开票状态；勾选“包含零库存批次”时才包含零库存。采购库存与产品库存完全分开。

以上文件按横向 A4、一页宽打印，长表纵向分页重复表头。到货导出需要采购到货权限，库存导出需要采购库存查看权限；没有采购价格权限时，文件不包含价格和金额字段。

新到货单与库存批次保存当时的订单、物品和库位资料，后续改名不改变历史单据。移库目标批次保存转库时的目标库位名称。升级前的旧记录只能按升级时的关联资料补齐一次，不能还原之前未保存的历史名称。
